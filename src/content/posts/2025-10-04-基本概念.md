冯 诺依曼 ：

```
1.计算机由五大部件组成
2.指令和数据以同等地位存于存储器，可按地址寻访
3.指令和数据用二进制表示
4.指令由操作码和地址码组成
5.存储程序
6.以运算器为中心
```

```
(核心部件 )

主存储器 ：
		存储体
		MAR
		MDR

**系统层次结构** ： 

微指令 ->  机器语言       |        ->  操作系统机器 ->  汇编语言机器-> 高级语言机器

（操作系统中 ， 计算机系统由下至上依次为**硬件、操作系统**、**应用程序和 用户** ）

```
第一层级（微程序层）M0
描述：由硬件直接执行的微指令（如微程序控制器），生成控制信号驱动电路。
特点：无符号的二进制控制信号，与物理硬件直接交互

第二层级（传统机器层）M1
描述：由微程序解释执行机器指令（如MOV, ADD等），对应CPU指令集。
特点：面向机器语言程序员，无需直接操作微指令。

第三层级（操作系统层）M2
描述：机器指令+广义指令（如文件操作、进程调度），通过操作系统程序实现
示例：调用open()函数时，操作系统将广义指令转换为底层机器指令组合。

第四层级（汇编语言层）M3
描述：汇编语言通过汇编器翻译为机器指令
 
第五层级（高级语言层）M4  ： 核心机制是编译而非解释。
描述：高级语言（如C、Python）编译优化后，运行于操作系统或虚拟机之上。


```

性能指标 ：

```
总容量  = 存储单元个数(MAR位数) * MDR(每个存储单元大小)

CPU 主频(时钟频率) = 1/CPU时钟周期 ， 也就是一个时钟周期所需时间     ： 10HZ 代表 1s 有 10 个CPU时钟周期 ：

CPI  :  执行一条指令 所需要时钟周期数 ： CPI * 1/CPU主频 * 总指令条数 = 所需总时间

IPS  :  每秒钟执行指令数量   = 主频 / CPI

(总指令数 / IPS = 所有指令所需总时间 )


FLOPS :  每秒钟执行 浮点数运算的次数  ( 其单位 同计网 K、M、G ， 不同于文件大小的 10-20-30)


系统整体 : 
		数据通路带宽 ：数据总线 一次所能 并行传送的 位数
		吞吐量 ： 系统在单位时间内处理请求的数量
		响应时间 ： 系统发出请求 ， 到获得所需结果时间


```

磁带存储器 ：





RAM ：
	SRAM ：(非破坏)  双稳态触发器： 不断电 触发器状态不会被改变
	
	DRAM ：(破坏性)  栅极电容 ： 电荷只维持2ms 就需刷新

			刷新寻址 ： 
					分散刷新  ：存取周期翻倍
					
					集中刷新  ：某段时间 “死区” ： 行数 * 存取周期
					
					异步刷新  ： 刷新周期内 每行刷新过即可  ：2ms / 行数 = 1次行刷新 （每次刷新内存在‘死区’）
		



ROM ：
	PROM的特点是用户只能通过专用编程器进行一次编程，编程后的内容无法被修改。
	紫外线擦除是EPROM（可擦除可编程只读存储器）的特性，
	
	Flash 存储器 ： （兼具低成本和高集成度）
			非易失性（长期保存信息）
			支持在线快速擦除与重写（电可擦除）


性能指标 ：  存储容量 = 字数 * 字长 
		   存储速度 ： 数据传输率 = 数据宽度 / 存储周期(读写周期/访问周期 ： 连续两次独立访问存储器操作)
           						带宽 = (数据宽度 / 8) × (1 / 存取周期) × 10⁹ （MB/s ： 10^6）
           						
		   (存取时间为从启动一次存储器操作到完成该操作所经历的时间，存储周期包含操作完成后的恢复时间)


基本组成 ： (半导体 和 芯片)
		
		地址总线的数量 : 决定了系统能够寻址的最大存储容量 ( 实际实现 其中的 部分地址线 ：省下不少成本和设计复杂度 )
		数据总线的数量 : 一个32位系统会有32根数据线 ， 可能使用4个8位宽的芯片或2个16位宽的芯片来匹配这个宽度


线理解 :  
		①地址线和存储单元数量相关

		②存储单元内的地址位数 决定了选通线的数量 (因为存储单元内的译码器通过选通线来找到对应的地址)

		③数据线的数量等于每个存储单元的大小。例如，每个存储单元存储 8 位数据，则数据线的数量为 8 根 (几个存储芯片)。

		④片选线用于选择特定的存储芯片，通常为 1 根。

		⑤读写控制线用于控制数据的读取和写入，通常为 2 根。
(控制总线不仅通过读/写信号区分总线周期类型，还需通过应答或时序信号确定输入/输出操作是否完成。因此，其功能不局限于读/写信号传输。)


(片选线选择芯片 ， 选通线操作读/写使能线 (RE/WE) ，选择具体存储单元)
(DRAM通过地址复用技术，将完整地址拆分为行、列两部分，分时送入数量减半的地址引脚 , 通过选通信号 ：RAS 和CAS 来决定行还是列 )

(片选线上的电平状态（即发送有效的片选信号）来决定特定的存储芯片单元：CPU就是用不同的片选信号来决定跟哪一单元“说话” )


存储体由行选择线和列选择线构成的存储矩阵组成，通过行列交叉确定存储单元位置。地址译码器负责将地址总线信号转换为行列选通信号，
而存储体是具体实现存储单元的物理结构



```



多体并行存储器 ： (T 为 存储周期 ， 存取时间为 r)

```
																	
	低位交叉编址 ： 宏观上读取一个字的时间为 r   ： 保证模块数 m>= T/r  （2^n=r×c，行数≤列数以降低刷新开销）
	
	地址最低 n 位（n=log₂(模块数)，此处 n=log₂4 =2）作为模块号，其余高位作为模块内地址。				
	
	(去除最低2位（右移2位）得到模块内地址  : 由二进制 移位转换 )

主存储器与CPU :

```

 位拓展 ：  数据总线连接多个存储芯片 (并行连接，分担数据。)
		   ( 也就是 通过 芯片并联 ， 比如有 8K *1 位 的芯片很多片  ， 13根数据总线连接即可)
 		   ( 地址总线数量与位扩展无关 )
 
 字拓展 ：  
 		低位部分（用于片内寻址，如A0-A9）
 		高位部分（用于选片，如A10）连接到一个地址译码器。
(CPU发一个地址，高位地址先进译码器，像个调度员，决定激活哪一个芯片。然后低位地址再告诉这个被激活的芯片，具体要它内部的哪一行数据)


流程 ： 比如说  有 8K *4位 ， 设计一个 32K×8位 的存储器  ，CPU地址线A15-A0，数据线D7-D0
	   那么 ， 8K =2^13 ,  32K = 2^5 × 2^10 = 2^15。需要15根地址线
	   片选地址线 ,还剩下 A14, A13 这两根高位地址线。它们的作用就是从4行芯片中选择一行。
	   译码器选择：用2根线（A14, A13）来产生4个独立的片选信号（每行一个），这正是 2-4线译码器 的功能
(先通过位拓展 ， 再字拓展)

	   
```





外存储器 ：  ( 与局部性原理并无直接关联 , 机械硬盘磁头寻道优化算法依赖于**物理运动优化算法** )

```

磁盘存储器(HDD) ： (磁记录原理的核心是磁头与磁性介质的相对运动，通过电磁转换实现数据读写)
		组成 ：
			磁头数 ：记录磁盘面数
			柱面数 ：记录每一个盘面有多少磁道
			扇区数 ：指盘面上的磁道有多少个扇区（被分为了几份）
		性能指标 ：
        	容量 ：
        	
        	记录密度 ：
        			道密度 : 磁盘半径方向上单位长度的磁道数
        			位密度 : 磁道单位长度上能记录的二进制代码位数 : 位密度从外道向内道增加
        			
        			面密度 : 位密度和道密度的乘积
        	        	
        	平均存取时间 ：
        			寻道时间 + 旋转延迟时间 + 传输时间  
        			( 旋转延迟 : 是等待目标扇区转到磁头下的时间，平均为转半圈的时间 )
        			
			数据传输率 ： 磁盘转数/s *每条磁道的N 个字节 （当磁头已经定位在某条磁道上）

		工作过程 :
			取址 , 读盘 , 写盘  : 先取控制字 , 再执行控制字  : 磁头移动方向 ,目标扇区地址 (磁头移动 , 数据传输)


		磁盘列阵 : ( 并行访问 , 数据分割存储 ) 
			
			RAID 0 : 无冗余、校验 
			
			RAID 1 : 镜像磁盘校验  ( 容量减半 )
			
			RAID 2 : 纠错的海明码 
			
			RAID 3 : "位"交叉奇偶校验  
									(RAID3 和 RAID4 都有独立校验盘 : 专用校验盘来存所有数据的奇偶校验值)
			RAID 4 : "块"交叉奇偶校验 :解决了RAID 3的并发读问题，但引入了写瓶颈。
			
			RAID 5 : 无独立校验的奇偶校
					(对 RAID 4 的改进 , 校验块“打散”分布在所有磁盘上 )
			

	磁盘高速缓存 : 核心功能是减少频繁的小块数据写入操作，通过按簇批量写入优化写性能。缓存机制也附带加速读取的效果
	
	
	
	
固态硬盘SSD : (基于 Flash , 电可擦 EEPROM)   
		组成 : 			
			闪存翻译层 : 将CPU的逻辑块读写请求转换为对闪存芯片的控制信号
			闪存芯片  
		
		磨损均衡 : 
			动态 : 写入时 , 优先累计擦除次数少的 新闪存快 (仅在数据写入时调整存储位置)
			静态 : 老的闪存块 以读为主 , 新的闪存快 以写为主 ( 主动监测闪存块的擦除次数 , 高磨损块的数据迁移到低磨损块 )
			
			
```





Cache :

```

	空间局部性 :  临近空间的使用
	
	时间局部性 :  一段时间的连续使用
	
	命中率  : 要访问的信息 在Cache中 的
	
	性能 :   访问主存时间 / 平均访问时间 
	


映射方式 : 
		全相联映射 :  (块号 = 	标记)
					主存地址 :  前几位 作为对比 Cache块的标记(块号) , 后几位 作为 块的地址  
				    存入时 , 将 块号 作为 Cache标志 , 可直接寻找
		
		直接映射 :  (块号 = 标记 + 行号)  , 使用无条件替换
					位置 = 主存块号 % Cache 总块数
				    可以确定 主存块 在哪一行 , 标记 记录是哪一块号
		
		组相连映射 :  (块号 = 标记 + 组号)
					所属分组 = 主存块号 % 分组数 	
					

	理解 : 如果一个组内有 k 行，就称为k路组相联
		  直接映射，可以看作是1路组相联
		  全相联映射，可以看作是C路组相联 : C为Cache总行数，整个Cache就是一个组

	换算 :  (算出 行数 ,  块大小 , 从而得出 Tag位数)
		直接映射 : Tag (标志) 位数: 总位数 - Index位数 - Offset位数
		
		组相联映射 : 根据给出的 路数  算出 组数 ,  即可得出 Tag 
				   寻找时 , 根据有效位判断是否命中
	
	


替换算法 : 
		RAND :  若 已满 , 随机替换
		
		FIFO :  先进先出
		
		LRU  :  设置计数器 , '近期最少使用的块' 被替换 
				命中时, 命中块的计数器归零 ,  数值 >= 该计数器 :  不变  , 数值 < 该计数器 : + 1 
				
		LFU  :  最少使用 , 记录 "块被访问的次数" , 替换最少次数的块
       
        
写策略 : 
			写命中 : 
					全写法 : 命中时 , 同时写回主存
					写回法 : 未被修改的块不必写回 : 块被换出时才写回主存 (脏位 为 1 , 写回)
			
			写不命中: 
					写分配法 :   块调入Cache , 配合写回法使用 
					非写分配法 : 仅更新主存单元，不涉及将主存块调入Cache的操作

```

指令 : 

```


(零地址指令仅包含操作码字段，没有显式地址码字段。其操作数通过隐含方式获取，例如：堆栈运算指令直接从栈顶获取操作数)

	指令的基本结构 : 
	
				操作码字段 : 
				地址码字段 : 提供操作数的地址或直接数据
			
	一地址指令 : 
	
				单操作数指令：指令中仅含有一个操作数地址，该操作数直接用于执行指令的操作
				(另一个操作数和结果放在一个CPU内默认的、隐含的累加器 (Accumulator, AC) 中)
				 
				隐含累加器参与：指令中包含一个显式操作数地址，另一个操作数则隐含在累加器中（通常是CPU中的寄存器）。

	二地址指令 : 
			格式: [ OP | A1 | A2 ]
			语义: (A1) OP (A2) -> A1 (将地址A1和A2的内容进行OP操作，结果覆盖A1)
	
	三地址指令 :
	
			格式: [ OP | A1 | A2 | A3 ]
			语义: (A1) OP (A2) -> A3 (将地址A1和A2的内容进行OP操作，结果存到地址A3)

	四地址指令 : 
			两个运算操作数的地址,运算结果存放的地址,下一条指令的地址
			
  
  
  
	扩展操作码 : (从地址长到短)
			
			指令字长的优化是通过平衡操作码长度和地址码数量的数量实现
		
			解题 : 找出最“贪婪”的指令，确定“逃逸出口”的数量 , 评估每个“出口”的“价值”：
	
			扩展操作码设计要点 :
			
					前缀规则：短操作码不能是长操作码的前缀。
					
					唯一性规则：所有操作码必须互不重复
					
					频率分配：高频指令用短码 , 低频指令用长码。
						
```

- 十进制：后缀`D`或省略（如`89D`或`89`）
- 十六进制：后缀`H`或前缀`0x`（如`3FH`或`0x3F`）

- char（8位）

- int（32位）
- long（32位机器为32位，64位机器为64位）

类型转换 规则 ： 

```
①
高位数据直接截断
低位数据完整保留
不进行符号扩展或补零操作
②
高位扩展规则：
无符号数：零扩展（高位补0）
有符号数：符号扩展（高位补符号位）


例如 ： 
32 位整数 0x12345678 的十六进制表示为 4 字节，从高位到低位依次为 0x12、0x34、0x56、0x78。转换为 8 位类型时，直接截断高位的 24 位，仅保留最低 8 位 0x78。

8 位有符号数 0x8F 的最高位为 1，表示负数。转换为 16 位时需进行符号扩展，高位补符号位 1，即 0xFF8F。

## 计算规则概念 ：





- 真值是指直接用正负号标识的数值  ` 对于-7，其真值就是-7。` 



**算术移位的规则**:





左移时，高位移出，低位补0，若移出的高位不同于移位后的符号位，即左移前后的符号位不同，则发生溢出;

右移时，低位移出，高位补符号位，若低位的1移出，则影响精度。例如，补码 1001和 0101 左移时会发生溢出，右移时会丢失精度。

( 逻辑位移 ： 单纯的 补“ **0** ” )

|   移位类型   |      操作对象       | 规则                                                         | 效果（数学意义）   |
| :----------: | :-----------------: | :----------------------------------------------------------- | :----------------- |
| **算术移位** | **有符号数 (补码)** | **左移**：低位补`0`，高位丢弃。<br>**右移**：高位补**符号位**，低位丢-弃。 | 近似 `×2` 或 `÷2`  |
| **逻辑移位** |    **无符号数**     | **左/右移**：统一在空出的位补`0`。                           | `×2` 或 `÷2`       |
| **循环移位** |       位模式        | **带进位(CF)**：CF参与循环。<br>**不带进位**：首尾相连循环。 | 用于位操作，如加密 |
